&#8203;AltLearn est une plateforme de gestion de l’apprentissage (LMS) conçue pour Epitech, avec une architecture découplée associant une API REST Node.js à un frontend React dynamique.

<div class="project-overview">

    <p class="project-lead">Ce projet met en œuvre une <strong>architecture côté client</strong> structurée, une intégration complète de l’API et des parcours adaptés aux rôles enseignant, administrateur et étudiant.</p>

            <ul>
                <li><strong>Interface interactive :</strong> développement des pages React d’inscription, de connexion, de cours, de leçons et de quiz.</li>

                <li><strong>Connexion à l’API :</strong> liaison des vues frontend à l’API REST Express via un proxy Vite optimisé.</li>
            </ul>

        <div class="col-md-6 mb-4">
            <h3><i class="fas fa-server"></i> Architecture du système</h3>
            <p>La plateforme repose sur une infrastructure backend sécurisée et évolutive :</p>
            <ul>
                <li><strong>Validation des données :</strong> schémas Zod stricts pour préserver l’intégrité des données sur chaque route.</li>
                <li><strong>Gestion des rôles :</strong> parcours d’authentification distincts pour le suivi étudiant et les tableaux de bord enseignants.</li>
                <li><strong>Organisation du travail :</strong> Git Flow, revues de code obligatoires et suivi des tâches sur Trello.</li>
            </ul>
