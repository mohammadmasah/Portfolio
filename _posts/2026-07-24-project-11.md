<div class="project-overview" lang="fr">
  <p class="project-lead">J’ai développé <strong>TrackIt</strong> pour réunir les candidatures, les contacts recruteurs et la préparation aux entretiens dans un même espace. Mon travail couvre le frontend React, avec un accent particulier sur <strong>le backend FastAPI, les données et l’intégration de l’intelligence artificielle</strong>.</p>

  <h2>L’IA au service de la candidature</h2>
  <div class="row">
    <div class="col-md-6">
      <h3><i class="fas fa-brain" aria-hidden="true"></i> Un assistant qui connaît le contexte</h3>
      <p>L’assistant utilise les informations des candidatures et des contacts pour fournir des réponses adaptées à la recherche d’emploi.</p>
      <ul>
        <li><strong>Choix du moteur :</strong> Ollama en local, ou OpenAI, Gemini et Claude avec une clé API personnelle.</li>
        <li><strong>Intégration LangChain :</strong> connexion de l’IA aux informations utiles de l’application.</li>
        <li><strong>Deux langues :</strong> échanges en français ou en anglais.</li>
      </ul>
    </div>
    <div class="col-md-6">
      <h3><i class="fas fa-comments" aria-hidden="true"></i> Des entretiens adaptés au poste</h3>
      <p>Un entraînement construit autour du poste choisi, avec des retours pour progresser d’une séance à l’autre.</p>
      <ul>
        <li><strong>Retours sur chaque réponse</strong> pendant l’entraînement.</li>
        <li><strong>Séances sauvegardées</strong> pour retrouver les préparations précédentes.</li>
        <li><strong>Bilan PDF</strong> présentant les points forts et les axes d’amélioration.</li>
      </ul>
    </div>
  </div>

  <h2>Un espace de travail pour toute la recherche</h2>
  <div class="row">
    <div class="col-md-6">
      <h3><i class="fas fa-columns" aria-hidden="true"></i> Suivre ses candidatures</h3>
      <p>Un tableau de bord pour consulter les statuts, enregistrer des favoris, rechercher et filtrer les offres, et repérer les candidatures à relancer.</p>
    </div>
    <div class="col-md-6">
      <h3><i class="fab fa-chrome" aria-hidden="true"></i> Capturer une offre depuis Chrome</h3>
      <p>L’extension Chrome permet d’enregistrer des offres depuis les sites compatibles pour les retrouver dans TrackIt.</p>
    </div>
    <div class="col-md-6">
      <h3><i class="fas fa-address-book" aria-hidden="true"></i> Retrouver contacts et documents</h3>
      <p>Les coordonnées des recruteurs et les pièces jointes restent associées aux candidatures pour préparer les échanges avec les bonnes informations.</p>
    </div>
    <div class="col-md-6">
      <h3><i class="fas fa-file-excel" aria-hidden="true"></i> Exporter ses données</h3>
      <p>Les candidatures peuvent être récupérées dans un fichier Excel structuré, en complément des bilans PDF de préparation aux entretiens.</p>
    </div>
  </div>

  <h2>Ma réalisation : backend, données et intégration IA</h2>
  <div class="row">
    <div class="col-md-6">
      <h3><i class="fas fa-server" aria-hidden="true"></i> API REST et authentification</h3>
      <ul>
        <li><strong>FastAPI :</strong> développement de l’API REST derrière les fonctionnalités de l’application.</li>
        <li><strong>JWT et cookies HttpOnly :</strong> mise en place de l’authentification.</li>
        <li><strong>React :</strong> conception du frontend et intégration avec l’API.</li>
      </ul>
    </div>
    <div class="col-md-6">
      <h3><i class="fas fa-database" aria-hidden="true"></i> Stockage et orchestration IA</h3>
      <ul>
        <li><strong>SQLite :</strong> stockage des données pour l’application locale.</li>
        <li><strong>PostgreSQL :</strong> base de données pour l’environnement Docker.</li>
        <li><strong>LangChain :</strong> intégration de l’IA avec le contexte des candidatures et des contacts.</li>
        <li><strong>Ollama ou API personnelle :</strong> choix entre exécution locale et fournisseur externe.</li>
      </ul>
    </div>
  </div>

  <div class="project-callout">
    <strong>De l’API à une application distribuable.</strong> TrackIt est disponible sur macOS, Windows et Linux avec une interface web locale et une mise à jour intégrée. J’ai automatisé les tests et les builds multiplateformes avec <strong>GitHub Actions</strong>. La version téléchargeable ne demande pas d’installation préalable de Docker, Python ou Node.js ; un environnement Docker est également proposé aux développeurs.
  </div>
  <p><strong>Projet open source :</strong> le code est accessible sur GitHub et la version 1.0.0 est disponible au téléchargement.</p>
